## Proyectos destacados

### [Critical_Scanning](https://github.com/CamiloDlRM/Critical_Scanning) — Infraestructura AWS con Terraform y Monitoreo Inteligente

Diseño e implementación de infraestructura completa en AWS utilizando Terraform como IaC. Incluye VPC con subnetting público y privado, Internet Gateway, Security Groups, IAM con mínimo privilegio, SSM, S3 y EC2 privada con Docker. Integra CloudWatch para monitoreo de métricas del servidor con función Lambda en Python potenciada con LLM para envío automatizado de alertas a Slack.

### Clúster Kubernetes para entornos educativos

Configuración y despliegue de clúster Kubernetes en 4 máquinas Orange Pi 5 Plus. Incluye preparación de servidores desde cero, hardening de seguridad, gestión de redes internas del clúster, DNS interno y despliegue de aplicaciones web en producción.

### Homelab Personal — Redes y Servicios Self-Hosted

Entorno homelab propio con servidores Linux para despliegue y gestión de servicios. Implementación de Cloudflare Tunnels para exposición segura sin apertura de puertos, DNS personalizado y certificados SSL/TLS. Complementado con laboratorios de red en Cisco Packet Tracer (TCP/IP, DNS, DHCP, VLANs, BGP/OSPF).

### [Plataforma ROBLE](https://virtual.roblehosting.site) — Hosting Automatizado

Sistema para el despliegue automático de proyectos académicos con Python, Docker y Coolify. Gestión centralizada de dominios y certificados SSL en producción.

### [ARKAD Platform](https://arkad.openlab.uninorte.edu.co) — Pipelines CI/CD

Diseño e implementación de pipelines de integración y despliegue continuo con GitHub Actions. Automatización de pruebas y manejo de múltiples entornos (desarrollo, staging y producción).

### [IA_Teach](https://github.com/CamiloDlRM/IA_Teach_API) — Backend con integración de IA

API backend con FastAPI e integración de modelos de IA (Gemini), desplegada en AWS EC2 mediante pipeline CI/CD con Docker y GitHub Actions.
